EGAC CONSTRUCTION - PROJECT IMAGE FOLDER
========================================

Drop this project's images in this folder:

    cover.webp   the card image on the home page and the top of the detail page
    01.webp      gallery images, in the order they should appear
    02.webp
    03.webp
    04.webp      (as many or as few as you have)

    project-video.mp4   optional - shown on the detail page if present

.jpg and .png work too. If you use a different extension, update the paths in
/js/projects.js for this project.

Images that do not exist are skipped automatically - nothing breaks and no
broken-image icon is shown.

Then open /js/projects.js and fill in this project's name, location, year,
categories, scope, description and materials.
